# Inspectra
Datasets used:
1. Surface Crack Dataset: https://www.kaggle.com/datasets/arunrk7/surface-crack-detection
2. PCB Defect dataset: https://www.kaggle.com/datasets/norbertelter/pcb-defect-dataset
3. Steel Defect Dataset: https://www.kaggle.com/competitions/severstal-steel-defect-detection/data
4. Bottles Dataset: https://data.mendeley.com/datasets/vk4hms8m6c/1
5. Welding Defect Dataset - Object Detection: https://www.kaggle.com/datasets/sukmaadhiwijaya/welding-defect-object-detection
6. Weld Defect Dataset: https://www.kaggle.com/datasets/sukmaadhiwijaya/weld-defect-detection-dataset
